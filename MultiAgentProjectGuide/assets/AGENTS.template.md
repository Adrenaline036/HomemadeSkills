# Agent collaboration entrypoint

For any multi-agent handoff, resumed implementation, review, `REVIEW.md`, `develop_log.md`, GitHub, CI, release, deployment, NAS, or media-library task, load and follow the installed `guide-multi-agent-project` Skill before editing.

Read `local/development/REVIEW.md` when present, inspect current Git state, declare role/scope/base commit, follow the standing authorization matrix, preserve unrelated changes, update collaboration records at material transitions, and finish with exact evidence plus a resumable handoff.

If the Skill or a required project file cannot be accessed, state the limitation and stop before uncovered external or destructive actions.
